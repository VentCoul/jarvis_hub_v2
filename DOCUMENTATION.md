# 📖 Документація Retail Management System v2.10 (Jarvis Edition)

## 📌 Огляд проекту
**Retail Management System (Jarvis Hub)** — це модульна асистентська система для автоматизації рутинних операцій у роздрібній торгівлі. Вона дозволяє швидко обробляти великі масиви даних (Excel звіти, файли сканування) та формувати готові вихідні дані для систем обліку.

---

## 🛠 Модулі та Функції

### 1. ⚡ Кліренс (Clearance)
**Функція:** `process_clearance_add`
**За що відповідає:** Пошук товарів, що підпадають під розпродаж (clearance), у поточному звіті залишків магазину.
**Логіка:**
- Зчитує офіційний звіт Кліренсу.
- Відфільтровує артикули за кодом вашого магазину.
- Шукає ці артикули у вашому звіті запасів (Inventory).
- Групує результат за штрихкодами (Barcode) та підсумовує кількість.
- **Вихід:** Список у форматі `ШК;Кількість`.

### 2. 🔍 Пропущені (Missed Items)
**Функція:** `process_missed_items`
**За що відповідає:** Виявлення товарів, які є на складі, але відсутні в торговому залі.
**Логіка:**
- Аналізує звіт запасів, де вказані локації (Склад vs Торговий зал).
- Шукає позиції, де `Кількість у залі <= 0`, а `Кількість на складі > 0`.
- Формує таблицю з сортуванням за стелажами (Shelf), що допомагає персоналу швидко винести товар у зал.
- **Вихід:** Таблиця Excel з деталями (Артикул, Полиця, Опис, Розмір, Кількість на складі).

### 3. 📦 Переведення (Movement)
**Функція:** `process_movement`
**За що відповідає:** Розподіл відсканованого товару на дві категорії: "Промо/Кліренс" та "Регулярний товар".
**Логіка:**
- Приймає файл сканування (текстовий список ШК).
- Співставляє кожен ШК з артикулом через звіт запасів.
- Перевіряє, чи є артикул у списку Кліренсу.
- **Вихід:** Три окремі списки (Promo, Regular, Combined) у форматі `ШК;Кількість`.

### 4. 🏷️ Переоцінка (Price Update)
**Функція:** `process_price_update`
**За що відповідає:** Підготовка даних для друку нових цінників або оновлення цін у системі.
**Логіка:**
- Зчитує файл переоцінки (список Артикулів або ШК).
- Знаходить ці позиції у вашому звіті запасів для отримання актуальних залишків та штрихкодів.
- Розділяє товари на Акційні та Звичайні.
- **Вихід:** Списки `ШК;Кількість` окремо для промо та регулярних товарів.

### 5. 🚚 Відправка (Shipping)
**Функція:** `process_shipping`
**За що відповідає:** Автоматичне заповнення шаблону накладної для відправки товару.
**Логіка:**
- Зчитує відскановані ШК.
- Підтягує Артикули та Розмір (Variant) зі звіту запасів.
- Заповнює Excel-шаблон, починаючи з рядка 4, по колонках: `1` — номер документа, `2` — номер лінії (крок 10000), `3` — артикул, `4` — кількість, `5` — розмір.
- **Вихід:** Готовий Excel файл накладної.

## 📂 Приклади файлів

### 📥 Вхідні файли (Input)
1.  **Inventory Report (Excel):**
    - Колонки: `ItemNo` (Артикул), `Barcode` (ШК), `Location` (Локація), `TotalQuantity` (Кількість), `Shelf` (Полиця).
2.  **Clearance Report (Excel):**
    - Колонки: `Article` (Артикул), `Store No` (Код магазину).
3.  **Scan File (TXT):**
    - Список штрихкодів (один на рядок).
    ```text
    4063697123456
    4063697123456
    4063697123457
    ```

### 📤 Вихідні файли (Output)
1.  **Format SKU;QTY (TXT):**
    - Використовується для імпорту в облікову систему.
    ```text
    4063697123456;2
    4063697123457;1
    ```
2.  **Missed Items Table (Excel):**
    - Зручний список для поповнення залу.

## 🚀 Як користуватися (Jarvis Edition)
Програма має GUI-інтерфейс на **PySide6** (Apple-inspired дизайн, світла/темна тема). Оберіть потрібний модуль на головному екрані, пройдіть кроки майстра (перетягніть або оберіть файли, вкажіть магазин/фільтри) та натисніть "Запустити". На екрані результатів збережіть вихідні файли кнопками (`.txt` у форматі `ШК;Кількість` або `.xlsx`).
